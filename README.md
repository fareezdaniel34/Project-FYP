# Staff Activity Management System

A web application for recording, managing and reporting staff activities. Staff log in to view and manage activities, and administrators oversee users and generate reports.

Built as our **Diploma in Information Technology (Digital Technology) final year project** at Politeknik Sultan Mizan Zainal Abidin, and awarded **Best FYP Project** (champion).

> **Team project** by [thrashraf](https://github.com/thrashraf), [fareezdaniel34](https://github.com/fareezdaniel34) and [adzrisya](https://github.com/adzrisya).
> Original repository: [thrashraf/Project-FYP](https://github.com/thrashraf/Project-FYP)

## Features

- **User accounts:** registration and secure login with JWT authentication and hashed passwords
- **Activity management:** staff activities displayed as cards with key details at a glance
- **Admin panel:** administrators manage users and activities
- **Reports:** generate activity reports as PDF
- **Responsive design:** works on desktop and mobile, with a collapsible navigation menu

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript, Redux Toolkit, React Router, Tailwind CSS, Axios |
| Backend | Node.js, Express |
| Database | MySQL |
| Security | JSON Web Tokens (access + refresh tokens), bcrypt |
| Collaboration | Git, GitHub (feature branches and pull requests) |
